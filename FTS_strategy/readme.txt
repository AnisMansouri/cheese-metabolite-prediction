1. script_feature_selection.R: performs the features selection step using Elastic Net.
2. script_rf_fts.R: used for the training and validation of the Random Forest models in the FTS strategy.
3. script_eigengene.R: used to compute the correlation between the selected features and the corresponding metabolite's amount.
4. script_ora.R: performs the over-representation analysis.
5. script_microbe_contribution.R: used to compute the contribution of each microbial species to the selected feature set.
6. script_growth_aroma.R: computes the correlation between the microbial growth and metabolites' amounts.
